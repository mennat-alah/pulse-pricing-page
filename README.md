# Pulse Pricing Page — HTML & CSS

A responsive recreation of the Pulse pricing page, built as a frontend practice project using HTML5 and CSS3.

## Project Overview

This project is a learning exercise based on the Pulse pricing page design provided by Frontend Practice.

The goal was to recreate the layout and styling from scratch while strengthening my understanding of HTML structure, CSS layouts, positioning, and responsive design.

## Features

- Navigation bar
- Pricing cards for different plans
- Customer testimonial section
- Frequently Asked Questions (FAQ)
- Footer with grouped navigation links
- Responsive layout adjustments for smaller screens
- Hover effects for links and buttons

## What I Learned

Through this project, I practiced:

- Building page layouts using CSS floats.
- Understanding the CSS box model, spacing, and alignment.
- Organizing HTML elements and choosing meaningful CSS class names.
- Using media queries to adapt layouts to different viewport sizes.
- Implementing hover states and reusable CSS rules.
- Translating a visual reference into a working webpage without relying on Bootstrap or Flexbox.
